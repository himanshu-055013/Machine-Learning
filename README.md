# Machine Learning for Managers (MLM) - PGDM (BDA) 2024-26

This repository contains projects, assignments, and exercises from the Machine Learning for Managers (MLM) core course, part of the PGDM (BDA) program for the 2024-26 batch at FORE School of Management.

**Course Overview:**

This core course introduces fundamental machine learning concepts and their application to business problems. Students will learn to develop and deploy machine learning models using Python and popular libraries such as Pandas, NumPy, Scikit-Learn, and more. The course emphasizes practical application and hands-on experience with real-world datasets.

**Key Topics Covered:**

* Basic Mathematical and Statistical Analysis with Python
* Inferential Statistics
* Regression (Linear and Logistic)
* Supervised Learning (Classification, Prediction)
* Unsupervised Learning (Clustering)
* Data Preprocessing
* Model Evaluation and Selection
* K-Nearest Neighbors (KNN)
* Decision Trees
* Ensemble Methods (Random Forest)

**Repository Structure:**

* **Assignments:** Contains assignments related to machine learning concepts and model building.
* **Projects:** Includes projects involving building supervised and unsupervised learning models.
* **Exercises:** Houses in-class exercises and practice problems.
* **Resources:** Links to relevant materials, recommended readings, and external resources.
* **Python:** Contains all the python code written during the duration of the course.

**Course Learning Objectives (CLOs) Addressed:**

* CLO1: Develop Working Knowledge of Machine Learning Algorithms
* CLO2: Analyze Big Data using appropriate Machine Learning Models
* CLO3: Build Machine Models on Big Data from Business / Management Domain
* CLO4: Prepare Analytical Reports based on Machine Learning Models

**How to Use This Repository:**

* Explore the project and assignment folders to understand the practical applications of MLM concepts.
* Review the code and documentation to learn from the solutions.
* Use the provided resources to further your understanding of machine learning technologies.
* Use the Python folder to review and practice the code written during the course.

**Prerequisites:**

* Data Exploration & Visualization using Python (DEVP)
* Statistical Methods for Data Analysis using Python (SMDAP)
